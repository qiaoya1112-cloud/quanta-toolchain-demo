# 公共表格列宽

由 table-columns.js 统一计算业务表格，包含左右各 16px 内边距。

- 复选框 48px，序号、开关 64px，优先级 80px。
- 标签按表头与最长标签的实际文字宽度计算，不分配剩余空间。
- 进度条按自身宽度加 32px；日期时间 180px。
- ID 按实际字体测量，在 120–320px 内配置；超过列宽时在列内换行。
- 名称最小 180px；描述、说明和数据范围最小 240px。文字列承接剩余空间，铺满可用宽度，操作和标签列不拉伸。
- 操作列取所有数据行按钮文字总宽、图标宽、12px 按钮间距和32px内边距的最大值，避免翻页变化。
- 容器不足时以最小列宽总和产生横向滚动；充足时仅文本列伸缩。全部短列允许留白。
- 保留已有固定列，随列宽更新左侧偏移和中间滚动条尺寸。
