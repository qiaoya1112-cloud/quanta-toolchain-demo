# 具身评测模块 MVP 原型设计

**设计日期**: 2026-08-06  
**文档版本**: v1.0  
**设计目的**: 为模型平台新增"具身评测"模块，支持评测集配置、评测任务管理、评测记录查看的完整闭环

---

## 1. 设计范围

基于 PRD 文档（`docs/eval-module-prd-hmi-quanta.md`），本次 MVP 原型聚焦**平台侧配置管理和结果展示**功能，不包含 HMI 端执行和数据采集（HMI 端改造独立进行）。

### 1.1 包含页面（7 个）

**配置管理类**（可交互原型，前端 JS 实现）：
1. 提示词库（列表 + 行内编辑）
2. Metric 模板（列表 + 创建/编辑）
3. 评测集管理（列表 + 创建/编辑）
4. 评测任务管理（列表 + 创建）

**结果展示类**（Mock 数据展示）：
5. Segment 列表（多维筛选 + 表格 + 导出）
6. Segment 详情（基本信息 + Metric 结果 + 过程数据占位）
7. （可选）Segment 统计分析

### 1.2 不包含内容

- HMI 端执行界面（解除头显限制、一键启动、异常操作等）
- 模型和代码部署管理（HMI 端同步处理）
- 数据湖底层接口（本次只做前端原型，后端接口暂用 Mock）
- P2 优先级功能（轨迹回放、BadCase 回流、权限管理、SQL 查询等）

## 2. 整体架构

### 2.1 模块定位

**新增独立模块**："具身评测"，与现有"评测"（双盲评测）分组并列，避免概念混淆。

### 2.2 导航结构

在 `PLATFORM_CONFIG["model"]["nav"]` 中新增分组：

```python
("具身评测", [
    ("/model/embodied-eval/prompts",     "提示词库",      "📝", "新增"),
    ("/model/embodied-eval/metrics",     "Metric 模板",   "📊", "新增"),
    ("/model/embodied-eval/sets",        "评测集",        "📋", "新增"),
    ("/model/embodied-eval/tasks",       "评测任务",      "⚙️",  "新增"),
    ("/model/embodied-eval/segments",    "评测记录",      "📄", "新增"),
]),
```

### 2.3 数据流关系

```
[配置阶段 - 平台]
提示词库 (Prompt 池) ────────┐
                            ↓ 选择 + 可编辑（快照式）
Metric 模板 (字段定义池) ────┤
                            ↓ 选择 + 可编辑
                      评测集（组装配置）
                            ↓ 关联
                      评测任务（执行计划）
                            ↓ 下发

[执行阶段 - HMI]
                      HMI 执行 + 填写 Metric + 上传
                            ↓ 生成

[结果阶段 - 平台]
                      Segment（评测记录）
                            ↓ 查看、筛选、分析、导出
```

### 2.4 关键设计原则

1. **提示词和 Metric 模板化**：可复用的配置资产，评测集从库中选择和组装
2. **快照式编辑**：评测集引用 Prompt 后的编辑不影响原库
3. **固定三层结构**：场景 → 任务 → Prompt（不支持任意层级，降低复杂度）
4. **Benchmark 是状态标记**：不独立成页面，作为评测集的一个属性
5. **单页长表单**：评测集创建用单页滚动，不用 Tab 分步

### 3.1 提示词库页面

**参考设计**：现有 Quanta 评测平台的"提示词管理"页面（用户提供截图）

**路由**：`/model/embodied-eval/prompts`

**布局**：

```
┌─ 顶部操作栏 ────────────────────────────────────────────┐
│ [Labels 下拉] [场景下拉] [任务下拉] [创建人] [🔍搜索] [🔄] │
│ [导入 JSON] [+ 新增提示词]                                │
└────────────────────────────────────────────────────────┘

┌─ 主表格区域 ────────────────────────────────────────────┐
│ Labels | 任务名称 | Prompt 文本 | 标签 | 创建人 | 操作     │
│ ──────────────────────────────────────────────────────│
│ 🔽 冰箱 (场景，合并单元格显示)                           │
│    │ 冰柜任务 │ 打开冰柜门 │ 开门动作 │ Li │ [复制][删除] │
│    │ 冰柜任务 │ 放置可乐   │ 放置     │ Li │ [复制][删除] │

└────────────────────────────────────────────────────────┘

底部分页：[10条/页] [< 1 2 3 4 >] [跳转]
```


**字段说明**：

| 字段 | 说明 | 数据源 |
|------|------|--------|
| Labels | 场景分类（如"冰箱""洗碗机"），支持合并单元格显示层级 | 用户输入或从已有场景选择 |
| 任务名称 | 二级分组（如"冰柜任务"），同一场景下可有多个任务 | 用户输入或从已有任务选择 |
| Prompt 文本 | 具体的测试指令文本 | 用户输入或导入 |
| 标签 | 可选标签（如"开门动作""放置"），多选 | 用户输入 |
| 创建人 | 自动记录 | 系统获取 |
| 操作 | 复制、删除 | - |

**关键交互**：

1. **行内新增**：
   - 点击"+ 新增提示词"，表格底部展开一行编辑区域
   - 场景/任务输入框支持自动补全（拉取已有的场景和任务）
   - 输入完成后点"保存"，该行固化成表格数据

2. **批量导入**：
   - 点击"导入 JSON"，弹窗上传文件
   - JSON 格式：`[{"scene": "冰箱", "task": "冰柜任务", "prompt": "打开冰柜门", "tags": ["开门动作"]}]`
   - 导入后按场景分组自动插入表格

3. **筛选**：
   - 顶部下拉可按场景/任务快速筛选
   - 搜索框支持 Prompt 文本关键词搜索

4. **层级展示**：
   - 场景用合并单元格显示（类似截图中的红框效果）
   - 同一场景下的任务和 Prompt 顺序排列

**关键交互**（按之前确定的 A 方案）：

1. **字段列表**：
   - 表头：`字段名 (flex:3)` | `类型 (flex:2)` | `操作 (固定宽)`
   - 每行：输入框 + 类型下拉 + 删除按钮

2. **枚举类型行内展开**：
   - 选择"枚举"后，该行下方展开浅蓝色区域
   - 显示标签式选项：`[success ✕] [timeout ✕] [error ✕] [+ 选项]`
   - 点"+ 选项"弹出输入框添加新选项
   - 点选项右侧 `✕` 删除该选项

3. **类型下拉选项**：
   - 整数
   - 浮点
   - 百分比
   - 布尔
   - 枚举（需额外配置选项）

**关键交互**：

1. **Metric 字段配置**：
   - 默认显示"从模板选择"单选按钮
   - 选中模板后，下方显示字段预览列表（标注"来自: XXX模板"）
   - 点"追加自定义字段"，切换到行内编辑模式（同 Metric 模板创建页）
   - 也可直接选"自定义字段"单选，从零开始配置

2. **Prompt 分组 - 添加场景**：
   - 点"+ 场景"，弹窗：
     - 输入场景名（支持自动补全已有场景）
     - 或从提示词库已有场景中选择
   - 确认后，树形结构中新增一个场景节点

3. **Prompt 分组 - 添加任务**：
   - 选中某个场景后，该场景下显示"+ 任务"按钮
   - 点击弹窗，输入任务名（同样支持自动补全）
   - 确认后，该场景下新增一个任务节点

4. **Prompt 分组 - 添加 Prompt**：
   - 选中某个任务后，任务下显示"+ 添加 Prompt"按钮
   - 点击弹窗，两个 Tab：
     - **Tab 1: 从库选择**
       - 列表显示提示词库的 Prompt（可按场景/任务筛选）
       - 支持多选勾选
       - 确认后批量添加到当前任务下
     - **Tab 2: 手动输入**
       - 文本框直接输入 Prompt 文本
       - 确认后添加到当前任务下
   
5. **Prompt 编辑（快照式）**：
   - 点某个 Prompt 的"编辑"，弹窗显示该 Prompt 文本
   - 修改后保存，**只改评测集内的副本**，不影响提示词库原始数据
   - 在 Prompt 右侧标记"(已编辑)"图标

## 9. 附录

### 9.1 参考文档

- PRD 文档: `docs/eval-module-prd-hmi-quanta.md`
- 现有代码: `toolchain_demo.py`
- 参考截图: 用户提供的提示词管理页面

### 9.2 关键决策记录

| 决策点 | 方案 | 理由 |
|-------|------|------|
| 新旧评测模块关系 | 全新独立模块并存 | 风险最低，不破坏现有双盲评测 |
| 导航组织 | 新增"具身评测"分组 | 界限清晰，避免概念混淆 |
| 评测集创建布局 | 单页长表单 | 一览性强，适合"配置一次就保存"场景 |
| Metric 编辑交互 | 枚举行内展开 | 所见即所得，不用反复开关弹窗 |
| Prompt 层级 | 固定三层（场景→任务→Prompt） | 实现简单，贴合真实数据结构 |
| Benchmark 处理 | 评测集的状态标记 | 不独立成页面，减少冗余 |
| Segment 范围 | 列表 + 详情页（含过程数据占位） | 展示完整闭环，为 P2 奠定基础 |
| 提示词库风格 | 对齐现有 Quanta 评测平台截图 | 保持风格一致性 |
| 部署功能 | 本次不做 | HMI 端处理，平台只记录信息 |
| 交互深度 | 可交互（前端 JS） | 能实际操作，最能展示产品形态 |

### 9.3 术语表

| 术语 | 说明 |
|------|------|
| 评测集 (Evaluation Set) | Prompt 的集合，相当于"卷子"，可版本化管理 |
| 评测任务 (Evaluation Task) | 一次具体的评测活动，指定评测集、模型、参数 |
| Segment | 评测结果的最小单元，对应一个 Prompt 在一个 Policy 下的一次执行 |
| Policy | 待评测的模型或策略，包含版本和 checkpoint |
| Metric | 评测结果的评分字段，可自定义字段名和值类型 |
| Benchmark | 固定的标准评测集，用于版本回归对比 |
| BadCase | 评测失败的案例，可回流训练数据湖 |
| 快照式编辑 | 评测集引用 Prompt 后的编辑不影响原库 |
| 行内展开 | 选择枚举类型后在该行下方展开选项编辑区域 |
| 固定三层 | 场景→任务→Prompt，不支持任意层级 |
