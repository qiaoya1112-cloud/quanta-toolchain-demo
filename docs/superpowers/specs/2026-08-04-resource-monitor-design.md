# 资源监控页面设计（模型平台 · 管理 > 资源监控）

## 背景

模型平台的训练任务实际通过调用火山云接口运行。需要在模型平台侧边栏新增「管理」栏目，下设「资源监控」二级菜单，展示火山云资源队列的使用情况。

页面参考火山引擎 ML 平台「队列列表」页设计。当前阶段只做队列列表，不含创建队列、不含队列详情页。

## 范围

**做：**
- 模型平台侧边栏新增「管理」组（置于「公共配置」组之后，即导航最末）
- 「资源监控」二级菜单 → `/model/resource-monitor` 页面
- 队列列表表格（8 列）
- 顶部工具栏：状态筛选、名称搜索、刷新
- 资源占用进度条（按占用率四档变色）

**不做：**
- 创建队列按钮 / 表单
- 队列详情页
- 真实数据接入（沿用 Mock 数据）

```python
("管理", [

```

## Mock 数据

`Section 1`，新增 `RESOURCE_QUEUES` 列表，约 6–7 项，覆盖三种状态（运行中 / 已停止 / 已关闭）。

每项结构：

```python
{
    "name": "...",                    # 队列名称
    "status": "running",              # running | stopped | closed
    "gpu":      {"used": 6,   "total": 8,   "unit": "", "model": "NVIDIA-A800-SXM4-80GB"},
    "vcpu":     {"used": 112, "total": 128, "unit": "vCPU"},
    "disk":     {"used": 1.2, "total": 2.0, "unit": "TiB"},   # 云盘
    "mem":      {"used": 1.9, "total": 1.9, "unit": "TiB"},   # MEM
    "ssd_flex": {"used": 0,   "total": 2.0, "unit": "TiB"},   # 极速型SSD flexPL
    "ssd_pl0":  {"used": 960, "total": 960, "unit": "GiB"},   # 极速型SSD PL0
}
```

数据设计覆盖各档占用率（含 0%、中段、100%），以便展示进度条四档配色。

## 页面布局

### 顶部工具栏（表格上方，靠左单行）

- 状态筛选下拉：全部 / 运行中 / 已停止 / 已关闭
- 名称搜索框：`placeholder="输入队列名称搜索"`
- 刷新按钮

纯 demo 交互：状态筛选与搜索走前端过滤（或 `toast` 占位），刷新 `toast` 占位。复用 `.fb-labeled` 或轻量 flex 工具栏。

### 表格（`.ant-table`，8 列）

| 列 | 内容 |
|----|------|
| 名称 | 队列名称文本 |
| 状态 | 彩色圆点 + 文字（绿=运行中 / 橙=已停止 / 灰=已关闭） |
| GPU | `已用/总量` 数字 + 进度条；数字下方额外一行小字显示 GPU 型号 |
| vCPU | `已用/总量 单位` 数字 + 进度条 |
| 云盘 | 同上 |
| MEM | 同上 |
| 极速型SSD flexPL | 同上 |
| 极速型SSD PL0 | 同上 |

资源列统一双行布局：上方 `已用/总量 单位` 数字，下方一条细进度条。GPU 列在数字与进度条之间/之后额外一行 GPU 型号小字。

## 进度条四档变色

新增 helper `res_bar(used, total, unit, model=None)`，按占用率输出对应 class + 数字文本 + 进度条 HTML。

占用率 → 配色：

| 占用率 | 颜色 | 用途 |
|--------|------|------|
| 0%–60% | 蓝绿 `#149DAA` | 正常 |
| 60%–85% | 黄 `#d4a017` | 偏高 |
| 85%–99% | 橙 `#E29845` | 高 |
| 100% | 红 `#cf1322` | 满载 |

新增 4 个 CSS 类（如 `.res-cell-bar.lv-low/.lv-mid/.lv-high/.lv-full`）控制 `.fill` 背景色。

**取舍说明：** 不复用现有 `progress_bar()`（其输出 `cur/total` 文本、仅三色、单行布局），而是专门新写 `res_bar()`。资源列是「数字 + 单位 + 型号 + 进度条」的多行结构，且按四档着色，与现有函数语义不同。新增不改动现有调用点，属手术式改动。

## 样式对齐

- 白色表格背景、浅灰表头（复用 `.ant-table`）
- 细分割线、紧凑行高（复用 `.ant-table` 现有 padding）
- 低饱和状态标识（圆点 + 文字）
- 细进度条（高度 6px，复用 `.track` 尺寸）
- 主题色 `#149DAA`

## 验收标准

1. 模型平台侧边栏最末出现「管理 > 资源监控」，点击进入页面
2. 页面顶部有状态筛选、名称搜索、刷新，无创建队列按钮
3. 表格 8 列齐全，字段与 spec 一致
4. 状态列圆点颜色正确（绿/橙/灰）
5. 资源列展示 `已用/总量`、进度条，GPU 列展示型号
6. 进度条颜色随占用率正确切换四档（构造覆盖 0%/中段/100% 的数据验证）
7. 无详情页跳转、无创建入口
