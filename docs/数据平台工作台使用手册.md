# 千寻数据平台工作台使用手册

## 1. 这份手册适合谁

如果你需要领取数据、完成质检或标注、处理被驳回的任务，或代替其他处理人完成当前节点，可以从“工作台”开始。本手册只介绍工作台相关页面和实际操作，不涉及任务配置、资源分配及用户组维护。

## 2. 进入工作台

使用飞书账号登录平台后，在左侧导航进入“工作台”。工作台首页有“任务池”和“待办项”两个页面：

- **任务池**适合领取新的工作。它告诉你各流程、节点还有多少数据待领取，以及你已经领取了多少。
- **待办项**适合继续处理已有工作，尤其是被驳回、需要补充或从其他入口转交给你的数据。

页面展示内容会随账号权限、所属项目和当前流程变化。如果看不到某个流程或节点，先确认登录账号和权限是否正确。

## 3. 从任务池领取并完成一条任务

### 3.1 找到可领取的任务

进入“任务池”后，先选择“流程”，再选择“节点”缩小范围。列表中的“待领取”表示仍可由你领取的数据量，“处理中”表示已经被领取、尚未提交的数据量。

找到目标节点后，点击对应任务的“开始处理”。系统会为你领取一条数据并打开对应工作台；如果待领取数量为 0，说明当前没有可领取数据，可以更换节点或稍后再试。

### 3.2 开始处理前先核对数据

进入工作台后，顶部会固定显示以下信息：任务 ID、处理任务、序列号、采集员、数据 ID。建议先核对任务和数据 ID，再开始播放视频或填写结果，避免误处理其他项目的数据。

### 3.3 播放和定位数据

工作台通常提供左臂视角、头部视角和右臂视角三路视频。你可以播放/暂停、放大画面，并拖动时间轴定位到目标片段。流程节点和时间轴上的标记用于提示当前数据需要关注的区间。

处理过程中需要暂时离开时，点击“暂离”。系统保留当前草稿并释放页面，之后可在“待办项”中继续处理。完成填写后点击“提交”，提交成功后数据会进入下一节点；不要连续重复点击提交。

## 4. 在待办项中继续工作

切换到“待办项”后，可以按数据 ID、处理任务、当前节点等条件筛选。列表会显示来源节点、当前节点、操作类型、驳回原因和更新时间，帮助你判断下一步要做什么。

点击一行的“处理”进入对应工作台：

1. 普通待办直接检查上一次保存的内容，补充缺失项后提交。
2. 如果操作类型为“驳回”，先阅读驳回原因，按原因修正质检结论、动作片段或语义描述，再点击“重新提交”。
3. 处理完成后回到待办项刷新列表，确认该条数据已从当前待办中移除或状态已更新。

## 5. 不同工作台怎么完成任务

### 5.1 质检工作台

播放问题区间并对照三路视频检查数据质量。选择质检结论，在问题说明中写清楚问题发生的时间段、现象和判断依据；需要退回时填写明确的驳回原因。确认结论和说明无误后点击“提交”。具备相应权限时，可点击“驳回”将数据退回上一处理节点。

### 5.2 动作标注工作台

在时间轴上定位动作起止位置，新增或编辑动作片段，填写开始时间、结束时间、时长、动作元素及动作描述。一个数据包含多个连续动作时，按实际发生顺序分别建立片段，并检查片段之间是否重叠或遗漏。完成后点击“提交”；被驳回的数据修改后使用“重新提交”。

### 5.3 语义标注工作台

先建立 High-level 语义，再在其下补充对应的 Low-level 语义，保持父子层级和时间范围一致。每个片段填写准确、可复核的描述；如页面要求选择错误原因，按实际情况选择并补充说明。检查层级、时间和描述后提交，需要退回时使用“驳回”。

### 5.4 详情工作台与代处理

从数据详情或待办项进入详情工作台时，页面默认是只读的，不会单独显示一组编辑控件。底部操作条只显示“代处理”。确认确实需要替他人完成当前节点时，点击“代处理”，页面切换为编辑态并显示该节点允许的操作；提交、驳回等动作会记录在日志中。

点击“查看日志”可以核对每次操作的时间、操作人、节点、动作和备注。遇到交接或争议时，先查看日志再继续修改。

## 6. 提交前自查

- 顶部任务 ID、处理任务和数据 ID 与当前工作一致。
- 视频已覆盖要求检查的区间，时间轴片段没有明显重叠或空缺。
- 质检结论、动作/语义内容和说明彼此一致。
- 驳回或代处理时填写了能让下一位处理人理解的原因和备注。
- 点击提交后看到成功反馈，并在待办项确认状态变化。

## 7. 常见问题

**任务池没有数据**：检查流程、节点筛选是否过窄；确认节点未暂停且仍有“待领取”数量。

**点击开始处理失败**：可能已被其他人领取、任务刚好被暂停或权限发生变化，刷新后重新尝试，仍失败时联系任务负责人。

**页面只有只读内容**：这是详情工作台的默认状态。确认有代处理权限后点击底部“代处理”；没有该按钮时不能直接编辑。

**被驳回后找不到数据**：在待办项按数据 ID或“驳回”操作类型筛选，打开后阅读驳回原因并重新提交。

**提交后列表没有变化**：先确认页面出现提交成功提示，再刷新待办项；不要在网络延迟时重复提交。
