# S026 指令采集交互演示实施说明

## 结论

本阶段将数据平台原有的“采集任务”入口升级为“指令管理”和“采集项目”两个独立入口。端侧采集不作为后台管理 Tab，而由采集项目详情的“端侧采集”按钮进入独立的手机 App 模拟页。页面不连接生产接口，不读取生产账号，不包含真实用户数据；所有业务记录都是虚构的本地 Mock，交互状态只保存在浏览器 `localStorage` 中，并支持一键重置。

## 现有项目技术栈与启动方式

项目是 Python Flask 单体 Web 演示。`toolchain_demo.py` 提供 Flask 应用、共享门户框架、全局样式和路由承载；`data_platform_refactor.py` 管理数据平台页面注册、导航、领域对象与页面渲染器；各页面使用服务端拼接 HTML，加原生 CSS 和 JavaScript 实现交互，不依赖 React、Vue 或前端构建工具。

本地启动：

```bash
pip install -r requirements.txt
python toolchain_demo.py
```

浏览器访问 `http://localhost:5004/data/instruction-management` 或 `http://localhost:5004/data/collection-projects`。生产式启动命令为 `gunicorn --bind 0.0.0.0:$PORT --workers 1 --timeout 120 toolchain_demo:app`，仓库同时保留 Render 蓝图。

## 当前页面结构

- 共享门户：顶部产品切换、数据平台侧栏、面包屑和内容容器。
- 数据采集：指令管理、采集项目两个入口；指令管理默认直接展示指令列表，不额外显示“指令库”入口；上传批次和审批任务使用独立子页面；项目详情内可进入端侧采集 App 模拟页。
- 数据处理：处理任务、分配管理、数据管理。
- 工作台：标注工作台。
- 工作流：流程管理、算子管理。
- 配置管理：规则管理、工作台管理。
- 运营管理：项目、用户组、供应商和权限管理。

## 附件提炼的核心流程

### 指令管理

1. 算法人员线下准备 XLSX 指令上传表。
2. 上传生成批次，系统校验字段、字典对应关系、指令正确性和重复性。
3. 合格批次发起审批；数据工厂逐条标记不合格版本并选择原因。
4. 完成审批后，未标记不合格的版本按合格处理，合格版本进入指令库并默认启用。
5. 指令及版本可启用或停用；停用只限制后续项目导入，不影响已有项目与任务。

演示页面中，上传文件会依次展示上传中、成功或失败状态，只有上传成功后才能确认生成批次；上传时间默认筛选演示日近 30 天并可自定义范围。校验、发起审批和删除均有二次确认。审批任务的查看与审批使用完整页面承载：列表和详情均支持多维筛选，详情提供分页，所有状态均可只读查看，仅审批中状态开放审批操作；选择“不合格”时通过弹窗选择原因并确认。

指令列表支持按指令 ID、名称、场景、工作区和状态筛选；版本详情依次展示版本号、版本名称、指令描述、镜像、难度、道具与采集进度。Mock 数据同时提供未达目标和超出目标两种采集进度，并提供新建、启用、停用指令及版本的更新日志。

### 采集项目

1. 创建名称唯一的采集项目。
2. 创建并发布版本化采集方案；同一项目只能有一个待发布方案和一个上线方案。
3. 从指令库批量导入启用版本，生成项目内独立维护的采集指令版本。
4. 按工作区和类似道具生成指令包，添加未编入成员并拖动排序；至少一个启用成员才可发布。
5. 从供应商库添加并启停供应商，查看执行进度。

### 端侧采集

1. 到达任务房源，选择项目和任务并绑定设备。
2. 查看指令包及道具，领取一个可执行指令包。
3. 按顺序执行指令，可采集或选择原因跳过。
4. 全部指令实例操作完成后提交指令包，再领取下一包。
5. 设备断开时禁止领取与采集；同一采集员同时最多领取一个指令包。

## 文档歧义与本阶段处理

- 在线采集是否保留：文档以问题形式出现。本阶段只展示离线采集。
- 单指令道具数量上限：文档标注“上限 30？”尚未确认。本阶段不做强校验，仅按少量道具演示。
- “检索与批量操作”多处标注待完善：本阶段实现核心关键词与状态筛选，不推断完整批量权限。
- 指令执行监控标注待完善：本阶段只提供只读 Mock 指标，不定义生产统计口径、刷新频率或导出规则。
- 多人同时审批的冲突合并规则未定义：本地演示采用最后一次操作结果，不作为生产并发方案。
- 项目、任务和房源的绑定入口与权限边界未完整描述：端侧使用预置虚构任务房源，并假定当前演示用户已有访问权限。
- 跳过次数跨时区、自然日结算与异常补偿规则未定义：页面展示规则但不实现生产级计数器。
- 采集时长汇总延迟、自动暂停任务的具体触发时机未定义：本阶段只展示阈值与状态，不实现后台调度。

## 实施文件与步骤

- `instruction_collection_demo.py`：新增 S026 本地 Mock 数据、页面结构、样式和交互状态机。
- `data_platform_refactor.py`：注册指令库、上传批次、审批任务、审批详情、采集项目和隐藏的端侧 App 路由，并将旧地址重定向到指令管理。
- `tests/test_instruction_collection_demo.py`：覆盖页面入口、核心文案、无网络请求、本地 Mock 和主要交互标识。
- `README.md`：补充 S026 演示入口与数据约束。

实施顺序为：读取并核对附件与现有代码；确定页面边界与 Mock 状态；实现后台双入口和独立端侧 App；补充回归测试；启动 Flask；在浏览器中验证上传校验审批、项目配置、指令包和端侧采集主链路；修复验证问题。
