## 三、核心要求

2. 从文档中提取实际出现的业务流程

4. 将抽象技术内容转化为产品功能语言

   - 页面上需要展示什么信息；
   - 需要哪些字段；
   - 会产生什么结果；
   - 与已有评测平台或 HMI 采集端有什么关系。

5. 每条需求必须标注来源  
   尽量写清楚需求来自哪个文档、哪个章节、哪个表格或哪段描述。

注意：不要强行判断。如果文档没有明确说明，请标记为“待确认”，并说明需要向业务方确认什么。
